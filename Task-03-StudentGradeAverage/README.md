# Task-03: Student Grade Average Calculator

## Objective

Develop a Java console application to calculate the total marks, average marks, and grade of a student using arrays.

## Features

- Accepts the number of subjects from the user
- Stores marks using arrays
- Calculates total marks
- Calculates average marks
- Determines student grade based on average
- Uses methods for better code organization

## Technologies Used

- Java
- Scanner Class
- Arrays
- Loops
- Methods
- Conditional Statements (if-else)

## Project Structure

## Sample Input

```
Enter Number of Subjects: 3

Enter Marks of Subject 1: 45
Enter Marks of Subject 2: 67
Enter Marks of Subject 3: 89
```

## Sample Output

```
========== RESULT ==========

Total Marks : 201
Average     : 67.0
Grade       : D
```
