# Task-04 - Random Password Generator

## Description

This project is a Java console application that generates a random password based on user preferences. The user can choose the password length and select which character types to include, such as uppercase letters, lowercase letters, numbers, and special characters.

## Features

- User-defined password length
- Include uppercase letters
- Include lowercase letters
- Include numbers
- Include special characters
- Random password generation
- Input validation for password length
- Handles the case when no character type is selected

## Technologies Used

- Java
- Scanner Class
- String
- StringBuilder
- Math.random()

## Sample Input

```
Enter the length of the password: 12
Include Uppercase (Y/N): Y
Include Lowercase (Y/N): Y
Include Numbers (Y/N): Y
Include Symbols (Y/N): N
```

## Sample Output

```
Generated Password: HCgd564Kzu0x
```
